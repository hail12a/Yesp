## Block, item and tool textures — Baunilha texture pack

The shipped textures for blocks, items and tools are derived from the
**Baunilha** texture pack for Luanti / Minetest Game (primary author
**Mirtilo**, with contributions from JoeEnderman, EmptyStar and others),
which builds on the Minetest Game default textures.

- **License:** Creative Commons Attribution-ShareAlike 4.0 International
  (CC BY-SA 4.0) — full text in `licenses/CC-BY-SA-4.0.txt`.
- Some individual assets in the pack are dedicated to the public domain
  (CC0) or licensed LGPL 2.1 by their respective authors; see
  `licenses/baunilha_custom_CREDITS.md` for per-file credits from the
  upstream pack, and `licenses/LGPL-2.1.txt`.
- These textures were applied to our nodes/items/tools by
  `mods/bc_core/reskin_baunilha.py`. Ore textures are composited from
  `default_stone` + the matching `default_mineral_*` overlay; the "gold"
  tool tier uses the pack's bronze tool art.

Because BlockCraft Modern distributes these CC BY-SA 4.0 textures, that
artwork (and any modifications to it) remains under CC BY-SA 4.0. This does
not affect the MIT license of the project's own code.

## Procedural fallback textures

A self-contained procedural texture set (bedrock, the furnace fuel/arrow
gauges, and the menu background, plus a full offline fallback for every
block/item/tool) is generated by `mods/bc_core/gen_textures.py` and is an
original work of this project, licensed CC BY-SA 4.0.

## Not included

The uploaded Asuna game code (`asuna_core`, `asuna_alias` by EmptyStar,
MIT) and the Everness / boulder `.mts` schematics are **not** part of this
game. They target a different (Minetest Game + Ethereal + Everness)
content set and are not used here.

## How to restore or change the look

```sh
cd mods/bc_core
python3 gen_textures.py                    # original procedural placeholders
python3 reskin_baunilha.py /path/to/pack   # re-apply a Baunilha-style pack
```
